# Memory Matrix

## Description

Memory Matrix is a React-based memory training game
designed to improve visual memory and concentration.

## Features

- Classic memory challenge
- Time Attack mode
- Game statistics
- LocalStorage persistence
- Difficulty levels

## Technologies

- React
- JavaScript
- Vitest
- React Testing Library
- GitHub Actions

## Atomic Design

The UI is organized using the Atomic Design methodology:
Atoms → Molecules → Organisms → Templates → Pages.

## Installation

npm install

## Development

npm run dev

## Testing

npm test

## Build

npm run build
